# VELOOP Rewards & Giveaways — Premium Watch & Earn

A polished React + Vite demo matching the supplied premium dark dashboard reference.

## Features
- Premium dark/blue/purple gradient dashboard
- Watch & Earn hero section with animated visual treatment
- 6 unique advertisement cards with reward and duration
- Countdown, progress and reward-success modal
- Already-watched state and persistent demo data with localStorage
- Daily progress, Daily Bonus, Recent Activity and balance cards
- Responsive sidebar/mobile layout
- Reset-demo button

## Run locally
```bash
npm install
npm run dev
```
Open the local Vite URL shown in the terminal.

## Production build
```bash
npm run build
npm run preview
```

## Netlify / Vercel
- Framework: Vite
- Build command: `npm run build`
- Publish/output directory: `dist`
- No environment variables are required for this frontend demo.

## GitHub structure
Upload the CONTENTS of this folder to the ROOT of your GitHub repository. `index.html`, `package.json`, `vite.config.js`, `src/`, and `public/` must be at repository root level.
