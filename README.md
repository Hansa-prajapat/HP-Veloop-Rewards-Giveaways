# VELOOP Rewards & Giveaways — Same Output UI

This is a standalone HTML/CSS/JavaScript implementation designed to closely match the uploaded VELOOP reference image.

## Run
1. Extract the ZIP.
2. Open the folder in VS Code.
3. Double-click `index.html`, or use VS Code Live Server.
4. No npm install is required.

## Netlify
- Drag the project folder (or ZIP) into Netlify Drop, OR connect the GitHub repository.
- Publish directory: `/` (root).
- Build command: leave empty.
- No environment variables are required for this static demo.

## Files
- `index.html` — complete UI and 8 screens
- `style.css` — dark neon/purple responsive styling
- `script.js` — buttons, timer, reward, bonus, gift-entry and toast interactions
- `design-reference.png` — uploaded reference image
